Sheet 02 — Method

Mark the whole line before the first cut.

  1. 01

    Survey the whole piece

    Automation, data model, integrations, permissions. A single request gets read against everything it touches.

  2. 02

    Find what’s under the sheets

    The overlapping flows, the code that won’t scale, the fix nobody wrote down. Found up front, not in production.

  3. 03

    Cut once

    Built to the plan in source control, tested, and deployed the same way every time.

  4. 04

    Leave it square

    Documented in words your team can use, so it keeps working long after I step away.
